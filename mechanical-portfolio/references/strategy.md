# 전략과 거래 이벤트

## 기본 전략

기준 스크리너는 `https://kr.tradingview.com/screener/7lL9VkT3/`다.
현재 화면의 저장 이름·시장·조건을 읽고 아래 계약과 비교한다.
변경이 있으면 차이를 기록하고 사용자 지정 변경인지 판단한다.

| 항목 | 기본값 |
|---|---|
| 시장 | 미국 상장 유니버스, 주된 상장 종목 |
| 시가총액 | USD 10,000,000,000 이상 |
| 후행 주가수익비율 | 0 이상 |
| 분기 매출의 전년 동기 대비 성장률 | 0% 초과 |
| 분기 순이익의 전년 동기 대비 성장률 | 0% 초과 |
| 목표 종목 수 | 15 |
| 새 편입 | 수동 제외를 뺀 상위 후보부터 빈 자리만 채움 |
| 기존 보유 | 전체 순위 `FinalRank` 20위까지 유지 |
| 교체 | 21위 이하, 실제 유니버스 이탈, 적용 중인 수동 제외 |
| 정기 비중 조정 | 매월 미국 시장 첫 거래일의 정규장 시가, 동일가중 |

미국 상장과 기업 국적은 다르다. 미국 기업만이라는 국적 제한이나 새로운
주식 종류·거래소 제한을 임의로 추가하지 않는다.

수동 제외 티커는 사용자 설정이나 등록된 Notion 목록에서 읽는다.
배포본에는 개인별 기피 종목을 기본값으로 고정하지 않는다.
제외가 변경되면 변경일·사유를 남기며 과거 결과에 소급 적용하지 않는다.
[Notion 기피 종목](notion-exclusions.md)이 등록되면 그 DB의 유효 기간을
기준으로 읽는다. 빈 활성 목록을 기존 상수로 바꾸지 않는다.

## 순위 계산

입력은 **확인한 동일 유니버스의 전체 행**이다. 상위 20개만 수집해서
전체 순위를 재계산하지 않는다. 필터 통과와 랭킹 필드 결측을 구분한다.

| 표준 필드 | 방향 | 가중치 |
|---|---|---|
| `MktCap_USD` | 클수록 높은 순위 | 35% |
| `ADTV_90D_USD` | 클수록 높은 순위 | 35% |
| `PSR` | 작을수록 높은 순위 | 15% |
| `RevenueGrowth_YoY_Q_%` | 클수록 높은 순위 | 15% |

각 항목의 순위는 `method=min` 방식이다. 같은 값은 같은 최상위 순위를 받고
다음 순위는 인원만큼 건너뛴다. 점수는
`0.35*r_marketcap + 0.35*r_adtv + 0.15*r_psr + 0.15*r_growth`다.
점수가 낮을수록 먼저 온다. 점수가 같으면 시가총액 내림차순,
그 다음 식별된 티커 오름차순으로 정렬해 재실행 순서를 고정한다.

먼저 전체의 `FinalRank`를 계산한 뒤 수동 제외를 표시하고 나머지에
`EligibleRank`를 붙인다. 보유 버퍼는 **FinalRank**다. 편입은 수동 제외를
건너뛴다. 두 순위를 섞으면 경계 종목의 매매 결과가 바뀐다.
시가총액·거래대금·P/S는 양수의 유한값이어야 한다. 기본 유니버스의 성장률도
양수다. 결측과 `—`를 0으로 채우지 않는다.

## 신규 생성

편입 가능한 상위 15종목에 각각 `1/15`의 목표 비중을 준다.
초기 자금이 없으면 NAV 100인 모델을 사용하고 이를 명시한다. 실계좌 투자액이나
기존 수량으로 오인할 금액을 발명하지 않는다. 종목이 15개보다 적으면 부족한
자리를 현금으로 남기고 후보 부족을 알린다.

개시 일시가 없으면 생성 시점 이후 이용 가능한 첫 정규장 시가를
모델 개시 예정으로 둔다. 아직 시가가 없으면 수량·체결가는 대기다.
과거 날짜의 시뮬레이션은 당시 유니버스·공시 시점을 확보했는지 검사한다.

## 월간 조정과 순위 이탈

월간 조정은 전체 보유의 동일가중 재조정이다. 월중에는 비중이 벌어졌다는
이유로 다시 맞추지 않는다. 상위 15에 새 종목이 들어와도 기존 종목이 20위
안에 있으면 유지한다.

순위 이탈은 확인 시점에 교체 이벤트를 확정하고 월간 조정일까지 기다리지 않는다.
모델 가격은 다음 규칙으로 정한다.

- 프리마켓·개장 전: 그 뒤 첫 정규장 첫 유효 1분봉 시가.
- 정규장 개장 시각 또는 개장 후: **다음 거래일** 첫 유효 정규장 1분봉 시가.
- 애프터마켓·휴장일: 다음 거래일 첫 유효 정규장 1분봉 시가.
- 첫 1분봉이 없으면 같은 정규장의 첫 실제 유효 1분봉을 사용한다.
  거래가 없는 날의 시가를 발명하지 않는다.

달력은 휴장일·조기 폐장·서머타임을 반영한다. 출력 일시는 KST다.
확인 전 시가로 소급 체결하지 않는다. 월중 교체는 매도 대금을 새 종목에
재투자하고 유지 종목의 비중은 재조정하지 않는다. 월간 조정과 겹치면
유효 체결 시점이 같은 경우에만 교체 구성을 정한 뒤 전체 동일가중을 한 번
계산한다. 첫 거래일 개장 후 발견한 이탈은 다음 거래일 교체 대상이며,
이미 지난 월간 조정 시가에 그 종목을 소급 반영하지 않는다.

## 결측과 원장

`확인된 순위`, `확인된 필터 탈락`, `자료 부족`을 구분한다.
부분 수집이거나 Yahoo 보정 뒤에도 보유 종목의 필수 필드가 없으면
데이터 확인 필요다. 그 누락만으로 매도를 확정하지 않는다.
새 후보 순위가 완전하게 검증되지 않으면 교체 매수도 대기한다.

분석은 매매 조건을 설명하되 원장을 변경하지 않는다. 원장 반영을
요청했다면 중복 이벤트를 검사하고 매도·매수·현금·수수료를 일관된 전환으로
기록한 뒤 보유·수량·현금을 다시 읽는다. 가격이 아직 없으면 계획만 보존한다.

로컬 기존 포트폴리오는 `portfolio/position_log.jsonl`이 기준이다.
Work에서는 제공된 원장/이벤트 파일 또는 명시적으로 등록된 원장을 사용한다.
지난 보고서의 보유 목록만으로 실제 수량이나 거래를 복원하지 않는다.
