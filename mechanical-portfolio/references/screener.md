# 스크리너 연결

기준 URL: `https://kr.tradingview.com/screener/7lL9VkT3/`

로컬과 ChatGPT Work 모두 **현재 호스트의 도구**를 탐색한다. 연결별로
`연결 식별자, 수집 경로, 스크리너 URL, 실제 조건, 수집시각, 원천 행 수,
전체 행 수, 중복/누락, 보정 필드`를 내부 근거로 보존한다.
스크리너 경로와 가격 제공자 순서는 독립적이다.
기본 작업에서 **스크리너 탐색·수집은 MCP를 쓰지 않는다.**
저장된 웹 화면에서 조건을 확인하고 허용된 HTTP 조회·로컬 수집기로 전체 행을
확보한다. 그 경로가 없거나 불완전하면 브라우저·CSV를 사용한다. MCP 스크리너나
필드 카탈로그를 먼저 호출해 실패를 반복하지 않는다.

| 경로 | 사용할 때 | 완료 근거 |
|---|---|---|
| 로컬 수집기/허용된 HTTP 조회 | 실행기·네트워크가 있고 현재 저장 조건을 재현함 | 요청 조건, 연속 페이지, totalCount, 중복·응답 검사 |
| 저장 스크리너의 웹브라우저 | 저장 조건 확인, HTTP 미지원·제한·필터 재현 불가 | URL·이름·필터·헤더, 전체 CSV 또는 모든 페이지/가상 행 |
| 사용자 제공/내보내기 CSV | Work의 연결이 제한되거나 검증된 내보내기가 있음 | 원천·시각·조건·전체 행 수·단위 |
| 검증된 과거 스냅샷 | 최신 경로가 모두 막힘 | 과거 기준일을 공개하고 참고용으로만 사용 |

성공 경로를 확보하면 다른 경로를 반복 호출하지 않는다. 과거 스냅샷으로 현재
매매를 확정하지 않는다. 상위 20개 캡처나 몇 행만으로 전체 순위를 만들지 않는다.

## MCP 연결 시험을 별도로 요청한 경우

아래는 사용자가 MCP 스크리너 연결 시험을 명시적으로 요청했을 때만 적용한다.
일반적인 종목 탐색·순위 점검에서는 이 절차를 실행하지 않는다. 가격 조회용
TradingView MCP 폴백은 [가격 제공자와 검증](prices.md)을 따른다.

요청 주소는 `https://mcp.tradingview.com/mcp`다. 호스트별 도구 이름을
고정하지 말고 실제 서버 URL 또는 도구 소속과 설명으로 연결을 찾는다.
현재 도구 목록·도구 검색의 TradingView MCP/플러그인과 스킬 목록의 연결 지침을
확인한다. 관련 스킬이 있으면 읽고 발견한 실제 연결 도구로 스크리너를 조회한다.
Alpaca Paper Trading은 가격 폴백이며 저장 스크리너를 읽는 도구가 아니다.

도구 설명에서 스크리너 실행, 컬럼 카탈로그, 종목 일괄 조회, 심볼 검색을 찾는다.
저장 URL을 받지 않는 도구에 URL을 임의 인자로 넣지 않는다. 저장 조건을 읽어
재현하고 미지원 조건은 한계로 표시한다. 현재 열 이름과 의미를 확인한다.
분기 YoY, TTM YoY, 분기 QoQ는 서로 다르다.

## 필드와 전체 수집 검증

HTTP·브라우저·CSV 등 실제 수집 경로의 필드 의미와 단위를 확인하고 아래 표로
표준화한다. 이 검증은 MCP를 쓰지 않는 기본 경로에도 적용한다.

| 원천 의미 / 로컬 기존 열 | 표준 필드 |
|---|---|
| `name`, 거래소+티커 `s` | `Ticker`, `SymbolFull` |
| `description` | `Company` |
| `market_cap_basic` | `MktCap_USD` |
| `AvgValue.Traded_90d` | `ADTV_90D_USD` |
| `price_sales_current` | `PSR` |
| 분기 매출 YoY (`total_revenue_yoy_growth_fq` 등) | `RevenueGrowth_YoY_Q_%` |
| `price_earnings_ttm` | `PE_TTM` |
| 분기 순이익 YoY (`net_income_yoy_growth_fq` 등) | `NetIncomeGrowth_YoY_Q_%` |
| `is_primary` | 주된 상장 여부 |

범위 필터가 `>=0`만 지원하면 더 넓게 받고 후처리로 `>0`을 적용한다.
주된 상장 여부 등을 지원하지 않으면 해당 열로 후처리하거나 검증된 전체
심볼 집합을 사용한다. `symbol_types=[stock]`가 ADR 등 기존 유니버스를 줄일 수
있으므로 임의로 추가하지 않는다.

반환량 제한에는 열 수·페이지 크기를 줄인다. 페이지/오프셋을 지원하면 끝까지
읽는다. 지원하지 않고 `totalCount > limit`이면 전체 수집으로 표시하지 않는다.
검증된 전체 심볼 집합이 있으면 지원 크기로 나누어 일괄 조회할 수 있다.
집합도 없다면 브라우저/CSV/HTTP로 전환한다. 임의 분할로 겹침·누락을 숨기지 않는다.
429/일시 오류는 제공된 대기 시간 또는 짧은 간격 뒤 한 번만 재시도한다.
반복 실패는 제한으로 기록하고 다른 경로로 전환한다. 프록시, 다른 계정, 숨은
세션 API로 제한을 우회하지 않는다.

## 브라우저와 CSV

현재 호스트 브라우저 도구의 지침을 따른다. Codex에서는 사용 가능한
브라우저/Aside를, Work에서는 그 호스트의 브라우저를 사용한다.
특정 데스크톱 앱, Chrome 프로필, CDP 주소를 필수로 두지 않는다.
관찰한 URL·헤더·필터를 읽고 사용자 저장 설정을 임의로 변경하지 않는다.

가상 스크롤 표의 한 번 읽기에 전체 행이 없을 수 있다. 페이지 이동/스크롤로
고유 심볼 수를 전체 수와 맞추거나 전체 CSV를 내보낸다. `B/M/T`, %, 통화,
소수점·천 단위를 명시적으로 변환한다. Mac의 한글 경로는 Python으로
NFD 정규화한다. Work의 첨부는 제공된 파일 참조를 사용한다.

## 로컬 수집기와 보정

기존 `portfolio_cli.py`는 TradingView 공개 scanner 요청에 조건을 명시하고
전체 페이지를 읽는다. `--screen-url`은 **referer**이며 저장 URL의 설정을
자동 읽는 기능이 아니다. 기본 시장·필터와 현재 화면을 대조한 뒤 사용한다.
Work에 코드가 없으면 해당 로컬 경로를 요구하지 않는다. 호스트가 허용하는
네트워크와 실행기가 있을 때만 검증된 요청을 재현한다.

최소 시가총액, 90일 거래대금, P/S, 분기 매출 YoY를 Yahoo로 보정한다.
유니버스 판정을 위해 필요하면 P/E·분기 순이익 YoY도 보완한다.
`priceToSalesTrailing12Months`가 없으면 같은 통화의 시가총액/TTM 매출로 계산한다.
`revenueGrowth`의 % 변환과 정확한 분기 YoY 의미를 확인한다.
TTM 성장률을 분기 성장률로 바꿔 넣지 않는다.

90일 거래대금은 원천과 같은 정의를 우선한다. `Close*Volume`의 90거래일
평균과 `현재가*평균거래량`은 다르다. 정의를 맞추지 못하면 근사치로 표시하고
경계 순위가 바뀌는지 검사한다. 10일 평균을 90일 값으로 숨겨 쓰지 않는다.
현재가는 Yahoo 우선 규칙으로 별도 확보한다.

원천 행을 보존하고 보정 필드·전후 값·출처·시각·통화 환산을 남긴다.
달러 시가총액과 엔화 매출 같은 통화 혼합을 먼저 해결한다.
화면 행 수와 HTTP 결과 수가 다르면 시간차·조건차·누락을 확인한다.
둘 중 편한 수를 완전성 검증에 사용하지 않는다.
