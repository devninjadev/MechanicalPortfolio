# 성과 계산 계약

이 문서는 기본 계산법을 고정한다. 사용자가 다른 계산법을 지정하면 그 지시를
따르고 표에 적용한 방식을 밝힌다. 같은 표 안에서 서로 다른 연환산·가격·배당
기준을 섞지 않는다. 기존 보고서와 방식이 다르면 단순 증감 비교를 하지 않는다.

## 입력과 평가

실제 이벤트를 `event_id, observed_at, effective_at, event_type, security_id,
quantity, unit_price, currency, fee, source` 등 원장의 실제 필드에 대응시킨다.
관측 시각은 판단 시점, 유효 시각은 가격·수량·현금에 반영한 시점이다.
체결이 없는 예정 이벤트는 일별 보유에 적용하지 않는다.
보유 목록만 있고 수량·현금·이벤트가 없으면 원장 성과를 재현했다고 부르지 않는다.

각 거래 후 현금은 매도 대금만큼 증가하고 매수 대금·수수료만큼 감소한다.
수량은 매수·매도를 반영하고 음수 현금·초과 매도가 나오면 원장을 먼저 확인한다.
월중 교체는 매도 대금으로 빈자리만 채운다. 월간 조정은 같은 유효 시점의
총자산을 기준으로 종목당 목표 비중 `1/15`를 계산한다. 소수 수량 허용 여부와
정수 수량으로 남는 현금을 명시한다. 자금이 작다고 음수 현금을 만들지 않는다.

분할일에 수량을 분할비율만큼 바꾸면 가격은 당시 명목 가격을 쓴다. 분할조정
가격과 당시 수량을 함께 써서 가치를 이중 조정하지 않는다. 배당은 포함할 때만
지급일 현금으로 반영하며 벤치마크도 같은 주가/총수익률 기준으로 맞춘다.

외부 자금 흐름은 투자 수익에서 제외한다. 당일 **시작**에만 외부 순입출금 `F_t`가
있으면 `r_t = NAV_t / (NAV_(t-1) + F_t) - 1`, 당일 **종료**에만 있으면
`r_t = (NAV_t - F_t) / NAV_(t-1) - 1`이다. 분모는 양수여야 한다.
장중 입출금은 각 흐름 전후 평가액으로 구간 수익률을 계산해 연결한다.
시각 또는 평가액이 없으면 정확한 시간가중 수익률은 미확인이다. 일별 흐름을
단순 차감한 근사치를 사용하면 그 가정과 이름을 따로 밝힌다.

수익 지수는 `W_0=1`, `W_t=W_(t-1)*(1+r_t)`로 연결한다.
자금 흐름이 없으면 `W_t=NAV_t/NAV_0`와 일치해야 한다.
시가 개시 모델의 첫 시가→종가 수익은 누적 곡선에는 포함하지만 일별 위험
통계에서는 완전한 종가→다음 종가 구간과 분리한다.

## 표본과 결측

완료된 미국 거래일 달력을 기준으로 평가한다. 주말·휴일을 전방 채워
0% 일수로 추가하지 않는다. 누락된 하루를 건너뛴 며칠 수익률을 1일 수익률로
계산하지 않는다. 일별 위험 통계와 Beta에는 두 끝 가격이 모두 확인된
**연속 거래일 구간**만 사용한다. 잠정 시간외 점은 제외한다.

기본 위험 통계는 연 252거래일, 표본 표준편차/분산 `ddof=1`이다.
무위험 수익률과 최소 허용 수익률은 별도 지정이 없으면 연 0%라는 계산 가정을
명시한다. 값이 지정되면 `r_f,d=(1+r_f,a)^(1/252)-1`로 바꾼다.
벤치마크와 포트폴리오의 비교 기간·세션은 같아야 한다. 뒤늦게 상장된 자산은
그 시작점을 밝히고 다른 자산의 전체 구간 통계와 우열을 단정하지 않는다.

## 통계 정의

아래에서 `n`은 유효 일별 수익률 수, `D`는 개시부터 마지막 확인점까지의
실제 경과 일수, `e_t=r_t-r_f,d`다. 낙폭 `d_t=W_t/max(W_0,...,W_t)-1`에는
개시 기준점도 포함한다. 수익률은 내부적으로 소수, 표에서는 %로 표시한다.

| 표 항목 | 계산 |
|---|---|
| 자산명 | 사용자 지정 표시 이름 또는 확인한 티커 |
| 누적 수익률 | `W_T-1` |
| 연환산 수익률(CAGR) | `W_T^(365.25/D)-1`; 실제 경과 일수 기준 |
| 최대 낙폭 | `min(d_t)`; 하락을 음수 %로 표시 |
| 연환산 변동성 | `std(r_t,ddof=1)*sqrt(252)` |
| 샤프 비율(Sharpe) | `mean(e_t)/std(e_t,ddof=1)*sqrt(252)` |
| 소르티노 비율(Sortino) | `mean(r_t-MAR_d)/sqrt(mean(min(r_t-MAR_d,0)^2))*sqrt(252)`; 분모는 전체 유효 일수 사용 |
| 켈리 추정치(Kelly) | `mean(e_t)/var(r_t,ddof=1)`; 일별 평균·분산 근사식, 투자 비중 지시로 사용하지 않음 |
| 궤양 지수(Ulcer Index) | `sqrt(mean((100*d_t)^2))`; %포인트 단위 |
| UPI | `100*(CAGR-r_f,a)/UlcerIndex` |
| 베타(Beta) | 같은 연속 거래일에 맞춘 `cov(r_asset,r_SPY,ddof=1)/var(r_SPY,ddof=1)`; 사용자 지정 기준 우선 |

표 머리글은 위 한국어를 우선 사용하고 필요한 약어만 병기한다.
`D<=0`, `W_T<=0`, 부족한 표본, 0 분모는 `—`로 표시하고 이유를 짧게 밝힌다.
30개 미만의 완전한 일별 수익률에서 위험 비율을 제시하면 표본 부족을 표시한다.
한 달 이하 CAGR은 연환산으로 크게 확대될 수 있으므로 누적 수익률과 기간을
함께 제시한다. NaN/무한대를 문자열 숫자처럼 표에 넣지 않는다.

## 수치 검산

- 이벤트 적용 전후 `현금 + 보유 평가액 = NAV`를 맞춘다.
- 외부 흐름 없는 구간에서 연결 수익 지수와 NAV 비율이 일치하는지 확인한다.
- 분할 전후 동일 보유 가치와 교체 매도·매수·현금의 일관성을 확인한다.
- 차트 최종점, 엔드 라벨, 본문 누적 수익률을 같은 원천 수치로 계산한다.
- 원장 기반 재현, 당시 정보 전략 백테스트, 현재 바스켓 과거 시뮬레이션의
  어느 결과인지 제목과 가정에서 일치시킨다.

기존 로컬 `_calc_stats_row`의 기본 연환산 365, 음수 일자만 사용하는 하방
분모, `ddof=0` 및 전방 채운 주말 자료는 이 계산 계약과 다르다.
그 결과를 새 표에 그대로 붙이지 않는다. 연속 거래일을 확보하고 위 기준으로
계산하거나 사용자가 지정한 기존 방식의 결과임을 명확히 표시한다.
